# 『불의 고리』 예약판매 구글 시트 사용 설명서

이 문서는 예약판매 실무자가 Google Sheets에서 주문을 확인하고, 입금 확인과 배송 명단 생성을 처리하는 방법을 정리한 운영용 안내서입니다.

## 1. 매일 볼 곳

실무자는 기본적으로 `예약자명단` 시트를 보면 됩니다.

`예약자명단`은 주문번호, 주문시각, 주문자, 연락처, 입금자명, 결제금액, 입금상태를 한국어로 보여주는 실무자용 화면입니다.

`Orders` 시트는 시스템 원장입니다. 영어 헤더가 있어도 정상입니다. 컬럼 이름을 바꾸거나 직접 수정하지 마세요.

## 2. 주문 상태 뜻

- `대기`: 주문은 접수됐고, 아직 입금 확인 전입니다.
- `입금확인`: 입금 확인이 끝났고, 배송 준비 대상입니다.
- `취소`: 취소된 주문입니다.

주문시각은 한국 시각으로 표시됩니다.

## 3. 처음 한 번 해야 할 일

스프레드시트를 열고 상단 메뉴에서 `불의 고리 주문`을 찾습니다.

처음 운영을 시작할 때만 아래 순서로 실행합니다.

1. `불의 고리 주문 → 1. 운영 시트 초기 세팅`
2. `불의 고리 주문 → 6. 주문 시트 권한 보호`

이후 평소 업무에서는 이 두 메뉴를 반복해서 누를 필요가 없습니다.

## 4. 새 주문 확인

새 주문이 들어오면 `예약자명단`에 표시됩니다.

화면이 최신 상태가 아닌 것 같으면 아래 메뉴를 누릅니다.

1. `불의 고리 주문 → 예약자 명단 새로고침`
2. 필요하면 `불의 고리 주문 → 2. 주문 현황 새로고침`

`운영대시보드`에서는 전체 주문 수, 입금확인 수량, 입금확인 금액을 한눈에 볼 수 있습니다.

## 5. 입금 확인 처리

은행 거래내역 CSV를 내려받은 뒤 아래 순서로 처리합니다.

1. 은행에서 거래내역 CSV를 다운로드합니다.
2. Google Sheets의 `입금CSV붙여넣기` 시트로 이동합니다.
3. A1부터 CSV 내용을 붙여넣습니다.
4. `불의 고리 주문 → 3. 입금 CSV 대사 미리보기`를 누릅니다.
5. `입금대사결과` 시트에서 결과를 확인합니다.
6. 문제가 없으면 `불의 고리 주문 → 4. 매칭분 입금확인 반영`을 누릅니다.

정상 매칭되려면 보통 아래 세 가지가 맞아야 합니다.

- 은행 거래내역 적요나 메모에 `HB-0001` 같은 주문번호가 있어야 합니다.
- 입금액이 주문 금액과 같아야 합니다.
- 입금자명이나 메모가 주문의 `입금자명`과 맞아야 합니다.

## 6. 수동으로 입금확인 또는 취소하기

CSV로 자동 매칭이 안 되는 주문은 직접 처리할 수 있습니다.

1. `예약자명단`, `Orders`, 또는 `입금대사결과`에서 해당 주문 행을 클릭합니다.
2. 입금 확인이면 `불의 고리 주문 → 선택 주문 입금확인`을 누릅니다.
3. 취소 처리면 `불의 고리 주문 → 선택 주문 취소`를 누릅니다.

주문번호가 있는 행을 선택해야 합니다.

## 7. 배송 명단 만들기

배송 준비 전 아래 메뉴를 누릅니다.

`불의 고리 주문 → 5. 배송 명단 생성`

그러면 `배송명단` 시트에 `입금확인` 상태 주문만 모입니다.

배송업체에 전달할 때는 `배송명단`만 사용하세요. 전체 주문 원장인 `Orders`를 그대로 전달하지 마세요.

## 8. 개인정보 주의사항

- 시트 공유는 실제 담당자에게만 허용합니다.
- 주문자 이름, 연락처, 주소가 보이는 화면을 외부 채팅방에 올리지 않습니다.
- 배송업체에는 배송에 필요한 정보만 전달합니다.
- 은행 CSV 파일과 배송용 파일은 업무가 끝난 뒤 정해진 보관 기간에 맞춰 삭제합니다.
- `Orders` 시트의 헤더, 컬럼 순서, 스크립트 속성은 임의로 바꾸지 않습니다.

## 9. 자주 생기는 상황

### 상단에 `불의 고리 주문` 메뉴가 안 보입니다

스프레드시트를 새로고침하세요. 그래도 안 보이면 관리자에게 Apps Script 권한이나 설치 상태를 확인해 달라고 요청합니다.

### 새 주문이 안 보입니다

`불의 고리 주문 → 예약자 명단 새로고침`을 눌러 보세요. 그래도 안 보이면 `Orders` 시트에 주문이 들어왔는지 확인합니다.

### 입금대사결과에 `확인필요`가 나옵니다

주문번호, 입금액, 입금자명이 맞는지 확인합니다. 맞는 주문이 확실하면 해당 행을 선택하고 `선택 주문 입금확인`으로 처리합니다.

### 주문번호 없이 입금된 건이 있습니다

입금자명과 금액으로 `예약자명단`에서 주문을 찾습니다. 확실히 같은 주문일 때만 수동으로 입금확인 처리합니다.

### 테스트 주문이 남아 있습니다

운영 시작 전에 테스트 주문은 `취소` 처리하거나 관리자와 상의해 원장에서 제외합니다.

## 10. 실무자 하루 업무 흐름

1. `예약자명단`에서 새 주문과 `대기` 상태를 확인합니다.
2. 은행 CSV를 `입금CSV붙여넣기`에 붙여넣습니다.
3. `입금 CSV 대사 미리보기`를 실행합니다.
4. `입금대사결과`에서 확인필요 건을 검토합니다.
5. `매칭분 입금확인 반영`을 실행합니다.
6. 배송 준비 시 `배송 명단 생성`을 실행합니다.
7. `배송명단`만 배송업체 업무에 사용합니다.
